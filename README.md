# Actividad Final EA3 - Manipulación de Árboles en Java ("Tree-Stock")

## Descripción y Teoría (ABB)
Un **Árbol Binario de Búsqueda (ABB o BST)** es una estructura de datos jerárquica donde cada nodo posee un valor clave y máximo dos hijos (izquierdo y derecho). Su propiedad fundamental es que los valores del subárbol izquierdo son menores que el nodo padre, y los valores del subárbol derecho son mayores. La **recursividad** se aplica para recorrer la jerarquía de forma eficiente tanto en la inserción como en las búsquedas y listados ordenados.

## Estructura del Código
- **`Producto.java`**: Actúa como el Nodo, conteniendo el identificador (`id`), el `nombre` y los punteros a los nodos hijos izquierdo y derecho.
- **`ArbolInventario.java`**: Contiene la lógica central del Árbol Binario de Búsqueda con los métodos recursivos de inserción, recorrido inorden y búsqueda.
- **`Main.java`**: Proporciona el menú interactivo por consola mediante un ciclo `do-while` y `switch-case`.
